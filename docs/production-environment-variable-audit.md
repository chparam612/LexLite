# Production Environment Variable Audit & Configuration Guide

> [!IMPORTANT]
> **CRITICAL SILENT FAILURE WARNING (`extra="ignore"`)**:
> `backend/app/core/config.py` uses Pydantic's `SettingsConfigDict(extra="ignore")`. 
> If you provide misspelled or outdated variable names (such as `BACKEND_CORS_ORIGINS` or `JWT_SECRET`), Pydantic **silently discards them** without raising an error. The application then falls back to localhost defaults (`CORS_ALLOWED_ORIGINS=["http://localhost:5173", ...]`), causing CORS errors on your live Vercel frontend!
> Always use the exact canonical names listed below.

---

## 1. Field-by-Field Cross Check: `render.yaml` vs `config.py`

| Config Model Field (`config.py`) | Blueprint EnvVar (`render.yaml`) | Status | Notes & Defaults |
| :--- | :--- | :--- | :--- |
| `APPLICATION_ENV` | `APPLICATION_ENV: production` | **MATCH** | Enforces production security checks (blocks test tokens, mock AI). |
| `ENVIRONMENT` | `ENVIRONMENT: production` | **MATCH** | Aliased to APPLICATION_ENV. |
| `STORAGE_BACKEND` | `STORAGE_BACKEND: local` | **MATCH** | Document storage backend (`local` or `gcs`). |
| `LOCAL_STORAGE_DIR` | `LOCAL_STORAGE_DIR: ./storage/uploads` | **MATCH** | Storage path for uploaded PDF/text documents. |
| `DATABASE_URL` | `fromDatabase: legal-ai-postgres` | **MATCH** | Auto-populated by Render Blueprint with PostgreSQL connection string. |
| `DATABASE_MODE` | `DATABASE_MODE: postgres` | **CONFIGURED** | Explicitly set to `postgres` to match Render Postgres. |
| `VECTOR_STORE` | `VECTOR_STORE: pgvector` | **CONFIGURED** | Connects to PostgreSQL pgvector for persistent vector embeddings across cold-starts. |
| `CORS_ALLOWED_ORIGINS` | `CORS_ALLOWED_ORIGINS: "*"` | **MATCH** | **NOT** `BACKEND_CORS_ORIGINS`. Can be `*` or comma-separated list of URLs. |
| `GEMINI_API_KEY` | `sync: false` | **MANUAL** | Required in production. Logged as WARNING on startup if missing. |
| `GEMINI_MODEL` | `GEMINI_MODEL: gemini-flash-latest`| **MATCH** | Default generation model. |
| `MAX_OUTPUT_TOKENS` | `MAX_OUTPUT_TOKENS: 2048` | **MATCH** | Coerced to integer. |
| `JWT_SECRET_KEY` | `generateValue: true` | **MATCH** | **NOT** `JWT_SECRET`. Auto-generated by Render Blueprint. |
| `FRONTEND_URL` | *(Optional)* | Default: `http://localhost:5173` | Set to your live Vercel URL (e.g., `https://<your-app>.vercel.app`). |
| `AI_PROVIDER` | *(Optional)* | Default: `gemini` | `gemini`, `groq`, or `local_llm`. |
| `GROQ_API_KEY` | *(Optional)* | Default: `None` | Set if using Groq (`AI_PROVIDER=groq`). |

## 2. Exact Key / Value List to Paste into Render Dashboard

If you configure environment variables manually in the Render Dashboard (**Dashboard -> Web Service -> Environment**), paste these exact key/value pairs:

```env
APPLICATION_ENV=production
ENVIRONMENT=production
STORAGE_BACKEND=local
LOCAL_STORAGE_DIR=./storage/uploads
DATABASE_MODE=postgres
VECTOR_STORE=pgvector
CORS_ALLOWED_ORIGINS=*
GEMINI_API_KEY=<your_actual_google_ai_studio_key>
GEMINI_MODEL=gemini-flash-latest
MAX_OUTPUT_TOKENS=2048
JWT_SECRET_KEY=<generate_random_64_char_string_or_leave_if_set_by_blueprint>
```

> [!NOTE]
> If you are using Groq instead of Gemini:
> ```env
> AI_PROVIDER=groq
> GROQ_API_KEY=gsk_...
> GROQ_MODEL=llama-3.3-70b-versatile
> ```

## 3. Frontend Environment Variables (Vercel)

Set in **Vercel Dashboard -> Project Settings -> Environment Variables**:

| Variable Name | Environment | Value | Description |
| :--- | :--- | :--- | :--- |
| `VITE_API_BASE_URL` | Production, Preview, Development | `https://legal-ai-backend-crc0.onrender.com` | Backend root URL. Do **NOT** add trailing slash `/` or `/api/v1`. |

> **IMPORTANT**: After modifying `VITE_API_BASE_URL` in Vercel, you must trigger a **Redeploy** (uncheck "Use existing build cache") so the build embeds the updated URL.
